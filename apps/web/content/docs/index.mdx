This template combines a static Fumadocs site, an MDX blog, and a client-rendered dashboard.

## Rendering model

- Public pages are prerendered during `bun run build`.
- `/dashboard/*` uses React Router's generated SPA fallback.
- Interactive application routes remain inside `apps/web`.
